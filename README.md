# Misioneros y Caníbales (Python)

Búsqueda en amplitud (BFS) y búsqueda en profundidad (DFS).

## Ejecutar
1. Instalar Python 3.8+ (Tkinter viene incluido; en Linux: `sudo apt install python3-tk`).
2. En la carpeta del proyecto: `python interfaz.py`
3. Botones: resolver con BFS, resolver con DFS, comparar ambos, reiniciar.

Solo la lógica por consola: `python busquedas.py`

## Archivos
- `busquedas.py`: formulación del problema, operadores, BFS y DFS (con métricas).
- `interfaz.py`: interfaz gráfica con animación y tabla comparativa.
